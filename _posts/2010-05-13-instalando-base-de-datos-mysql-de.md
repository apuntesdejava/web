NetBeans con JavaDB (Apache Derby) viene con unas bases de datos ejemplos, que son justamente los que se han usado en los tutoriales de este blog. Iba a hacer una demostración de cómo se instala la base de datos [SAKILA](http://dev.mysql.com/doc/sakila/en/sakila.html) de MySQL para un tutorial que iba hacer, pero encontré el [plugin para NetBeans](http://wiki.netbeans.org/SakilaSampleDatabasePlugin).

Así que muestro un vídeo de cómo instalar este Plugin, además de cómo crear la base de datos de ejemplo desde NetBeans.

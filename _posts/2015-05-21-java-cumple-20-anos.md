Celebramos 20 años desde que salió a la luz la primera versión de Java y puesta para uso público. Desde entonces más de 9 millones de desarrolladores de Java lo trabajan en la mayoría de las industrias. La comunidad Java constantemente está innovando y cambiando nuestros días normales.

Podemos encontrarlo ayudando en la seguridad del [camino](http://www.perronerobotics.com/) y el [aire](http://www.dhmi.gov.tr/home.aspx), [recopilando información desde los océanos del mundo](http://www.liquidr.com/) para aplicaciones de ciencias, simulando cerebros humanos y sistemas musculo-esqueléticos, y en los [juegos](http://www.oracle.com/us/corporate/features/kids-code-java/index.html).

Java está caracterizado por lo siguiente:

- Simple

- Orientado a objetos

- Distribuido

- Multiprocesamiento

- Dinámico

- Arquitectura neutra (multiplataforma)

- Portable

- Alto rendimiento

- Robusto

- Seguro

Cada uno de estas características está explicado en "[The Java Language Environment](http://www.oracle.com/technetwork/java/langenv-140151.html)" (1996) escrito por James Gosling y Henry McGilton.

Oracle y la comunidad Java está ahora enfocado en el lanzamiento de [Java 9 con interesantes innovaciones](http://openjdk.java.net/projects/jdk9/). La característica clave de esta versión es el [proyecto Jigsaw](http://openjdk.java.net/projects/jigsaw/), el cual apunta a modularizar la plataforma de tal manera que sea escalable al tamaño del dispositivo, de tal manera que sea fácil para los desarrolladores para construir y mantener bibliotecas y grandes aplicaciones, mejorar la seguridad y mejorar el rendimiento. Otra característica para Java9 es la inclusión del [Java Shell](http://openjdk.java.net/jeps/222), una herramienta interactiva para evaluar fragmentos de código Java; un nuevo [API para cliente HTTP](http://openjdk.java.net/jeps/110) que soporte [HTTP/2](http://http2.github.io/) y Web Sockets.

Como parte de la celebración, la certificación de Oracle ofrece 20% de descuentos en todos los exámenes de certificación Java. Se ofrece mundialmente hasta el 31 de diciembre de 2015. Deberán usar la clave de promoción **Java20**. (20% por 20 años... ¿y cuando cumpla los 100 años? je)

¡Feliz aniversario, Java!

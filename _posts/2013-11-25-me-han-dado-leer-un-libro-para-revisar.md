Me han dado a leer un libro para revisar y dar mi opinión al respecto. A pesar que no es Java, me pareció interesante verlo ya que trata del HTML5 y JavaScript.

El libro se llama "[Developing Windows Store Apps with HTML5 and JavaScript](http://bit.ly/178s4mI)" Si eres desarrollador web, y deseas desarrollar aplicaciones para Windows8, este libro te podrá interesar.

Los primeros dos capítulos hacen una mención muy concisa sobre el HTML5 y CSS3. Los conceptos son claros, y bien detallados sobre los atributos. Cuando trata el CSS3, menciona sobre los atributos adicionales que maneja el MSIE para mejorar la distribución de los componentes.

La sección de JavaScript para Windows Apps hace una total referencia para  clase WinJS. No estoy seguro, pero creo que es una herencia de JQuery.

Después de hacer una gran introducción de lo que se va a trabajar, comienza a mencionar las herramientas para poder hacer aplicaciones para Windows 8, tales como Visual Studio 2012 (express), Windows 8 SDK y otros componentes.

Todo lo mencionado en el HTML5  / CSS3 es elaborado en los siguientes capítulos usando el Visual Studio. También hay una sección para manejo de data en la interfaz gráfica usando el formato JSON, manejo de listas de datos en tablas.

Lo que está de moda son las aplicaciones web Responsive, y este tema no está excluido del libro.

Finalmente, menciona sobre cómo mostrar la aplicación como un azulejo (Tile) y cómo manejar el área de notificaciones. Así como también la autenticación de la aplicación y el uso del SSO sobre entornos de Microsoft Live.

Este libro está bien elaborado, ya que cubre todos los aspectos básicos y concretos que debería tener una aplicación HTML5 para Windows 8. Si tienes algo de noción web y quieres hacer una aplicación para usuarios exquisitos de Windows 8, te recomiendo que adquieras este libro. No te vas a arrepentir.

Se encuentra disponible [NetBeans IDE Early Access for PHP](http://download.netbeans.org/netbeans/6.1/final/) que es el IDE NetBeans exclusivamente para desarrollar en PHP.

Para usarlo, se necesita lo siguiente:

- El IDE NetBeans Early Access for PHP, que se encuentra [aquí](http://download.netbeans.org/netbeans/6.1/final/).
- Un servidor Web, de preferencia [Apache Server](http://httpd.apache.org).
- El [PHP 5.0](http://www.php.net).
- Y, opcionalmente, el xdebug que es el depurador de PHP 5.0 y se puede encontrar [aquí](http://www.xdebug.org/).
Se puede obtener el MySQL + PHP + Apache utilizando algún paquete WAMP que consiste en un conjunto de software que contiene Apache + MySQL + PHP para Windows.

Si quieres aprender a programar en web como debe ser, usando el patrón MVC, no hay nada mejor que hacerlo con Spring MVC. Y este libro será de gran ayuda.

Es una guía para principiantes, para los que no conocen Spring MVC. Está muy buen redacta, bien explicado, y en cada paso está explicado qué pasó.

Aprenderás hacer desde una aplicación MVC simple, hasta implementar REST. También aprenderás a usar plantillas con [Apache Tiles](https://tiles.apache.org/), a usar pruebas unitarias integradas al Spring.

Debes conocer algo de java web como Servlet y JSP. Todo lo demás el Spring MVC te ayudará.

Este libro lo puedes adquirir aquí: [http://bit.ly/1joTujv](http://bit.ly/1joTujv)

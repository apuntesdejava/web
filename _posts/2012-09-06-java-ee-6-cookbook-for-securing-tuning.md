[@Mick Knutson](https://twitter.com/mickknutson) publica su libro "[Java EE 6 Cookbook for Securing, Tuning, and Extending Enterprise Applications](http://www.packtpub.com/java-ee6-securing-tuning-extending-enterprise-applications-cookbook/book)" donde se muestra, de manera general y concisa, los aspectos de seguridad, rendimiento y mejorar las aplicaciones Java EE 6. Aquí, mis comentarios del libro.

Comienza en libro con una revisión de las antiguas APIs de Java EE,  y da a entender cuales son las dificultades de su implementación, qué se "podó" de la antigua especificación, y cómo lo mejoraron. Es una sección muy bien documentada, y sirve como hacer un poco de historia de Java EE.

El método de lectura del libro es bastante dinámico: por cada tema se describe la característica de la especificación ("Get Ready"), luego explica cómo se usa ("How to do it..."), sigue con la explicación de cómo trabaja ("how it works...") y deja bibliografía para que uno siga revisando.

Las extensiones a Java EE son muy bien explicadas. Se presenta la integración con Groovy, Jython (Python en Java), Scala, AspectJ, Mobile. El monitoreo con Java Visual VM no se queda atrás. El capítulo 8 "Perfomance and Debugging" no se debe dejar de leer.

Si uno tiene un conocimiento básico de Java EE6, este libro le vendrá muy bien, ya que cubre varios aspectos de la tecnología con ejemplos bien explicados y deja ese *sabor en la boca* de querer más.

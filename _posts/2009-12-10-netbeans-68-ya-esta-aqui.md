NetBeans 6.8 ya salió a la luz.

Es el primer IDE que soporta Java EE6, incluyendo Java EE Web Profiles, EJB 3.1, JPA 2.0,  GlassFish Metro 2.0 web services (JAX-WS 2.2),  JAXB 2.2.

También crea aplicaciones JavaFX 1.2.1. Soporte completo para PHP 5.3 (con namespaces) y [muchas características más](http://netbeans.org/community/releases/68/).

Puedes descargarlo de aquí: [http://netbeans.org/downloads/?pagelang=es](http://netbeans.org/downloads/?pagelang=es)...

Si quieres ver a NetBeans 6.8 en acción, revisa los siguientes vídeos: [http://netbeans.org/kb/docs/intro-screencasts.html](http://netbeans.org/kb/docs/intro-screencasts.html)
